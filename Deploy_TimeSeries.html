Pengumpulan dan Pembacaan Data#

Tahap awal dilakukan dengan membaca data kadar NO₂ yang tersimpan pada file NO2_Manyar.csv. File cek_data.py digunakan untuk melakukan eksplorasi awal seperti menampilkan beberapa baris data pertama, memeriksa tipe data, serta memastikan tidak ada nilai yang hilang atau tidak valid. Langkah ini penting agar data yang digunakan pada tahap pemodelan benar-benar bersih dan siap diolah.

File cek_data.py digunakan untuk memeriksa kondisi awal dataset NO₂ Manyar sebelum dilakukan pemrosesan atau pelatihan model.
Langkah ini penting agar kita mengetahui:

  • Struktur data (berapa banyak kolom dan jenis datanya)

  • Apakah data sudah bersih atau masih ada masalah (seperti missing value atau tipe data yang salah)

  • Gambaran umum isi dataset

Penjelasan setiap bagian kode:

  1. Import pustaka pandas
    Digunakan untuk membaca dan mengelola data dalam bentuk tabel (DataFrame).

  2. Membaca file CSV
    Kode pd.read_csv("data/NO2_Manyar.csv") membuka file dataset yang berisi data pengukuran konsentrasi NO₂ di wilayah Manyar.

  3. Menampilkan 5 baris pertama
    Bagian df.head() digunakan untuk melihat contoh data di awal agar kita tahu kolom apa saja yang tersedia dan format nilainya.

  4. Menampilkan tipe data setiap kolom
    Dengan df.dtypes, kita bisa mengetahui apakah kolom berisi angka (numerik), tanggal, atau teks — penting agar tidak terjadi kesalahan dalam analisis.

  5. Menampilkan informasi umum dataset
    Fungsi df.info() memperlihatkan jumlah baris, kolom, tipe data, dan apakah ada nilai yang hilang (null).

Secara keseluruhan, file ini membantu memastikan bahwa dataset siap digunakan sebelum dilanjutkan ke tahap pra-pemrosesan atau pembuatan model prediksi.

Pemrosesan Data dan Normalisasi#

Sebelum digunakan untuk pelatihan model, data numerik dinormalisasi agar setiap fitur memiliki skala yang seimbang. Proses normalisasi dilakukan dengan menggunakan StandardScaler, kemudian hasilnya disimpan dalam file scaler.pkl untuk digunakan kembali pada tahap prediksi. File utils.py dalam folder details berisi fungsi-fungsi pendukung seperti transformasi data, pembentukan dataset time series, atau perhitungan tambahan yang dibutuhkan oleh model.

Kode pada file details/utils.py berfungsi untuk memuat data secara aman dan efisien. Fungsi load_data(path) akan memeriksa apakah file dataset ada di lokasi yang ditentukan. Jika tidak ditemukan, program menampilkan pesan kesalahan. Jika file ada, data dibaca menggunakan pandas.read_csv() dan dikembalikan dalam bentuk DataFrame. Dengan cara ini, proses pemanggilan data pada aplikasi menjadi lebih praktis dan terhindar dari error akibat file yang hilang.

import pandas as pd
import os

def load_data(path):
    if not os.path.exists(path):
        raise FileNotFoundError(f"File data tidak ditemukan: {path}")
    return pd.read_csv(path)

Pembuatan dan Pelatihan Model KNN Regressor#

Tahap ini merupakan proses utama dalam pembangunan model prediksi. File train_model.py berisi langkah-langkah pelatihan model KNN menggunakan data yang telah diproses. Sedangkan knn_model.py digunakan untuk mendefinisikan arsitektur model dan metode prediksi menggunakan algoritma K-Nearest Neighbors Regressor. Setelah proses pelatihan selesai, model disimpan dalam bentuk file knn_model.pkl agar dapat digunakan kembali tanpa perlu melatih ulang.

Kode pada file train_model.py berfungsi untuk melatih model K-Nearest Neighbors (KNN) yang digunakan dalam memprediksi konsentrasi NO₂ di Manyar. Pertama, program membaca dataset dan membersihkan data dari nilai kosong. Kemudian dibuat fitur lag untuk menangkap pola autokorelasi, yaitu hubungan nilai NO₂ hari ini dengan beberapa hari sebelumnya. Setelah itu, data dibagi menjadi data latih dan uji tanpa pengacakan agar urutan waktu tetap terjaga. Tahap selanjutnya dilakukan normalisasi data menggunakan StandardScaler agar setiap fitur memiliki skala yang seimbang. Model KNN kemudian dilatih menggunakan data tersebut dan dievaluasi menggunakan MAPE (Mean Absolute Percentage Error) untuk mengukur tingkat kesalahan prediksi. Terakhir, model dan scaler disimpan dalam bentuk file .pkl agar dapat digunakan kembali oleh aplikasi Streamlit tanpa perlu pelatihan ulang.

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsRegressor
from sklearn.metrics import mean_absolute_percentage_error
import joblib
import os

# === 1. Baca dataset ===
data_path = "data/NO2_Manyar.csv"
df = pd.read_csv(data_path)
df['time'] = pd.to_datetime(df['time'])
df = df.dropna(subset=['NO2'])

# === 2. Buat fitur lag (autokorelasi) ===
def create_lag_features(df, target_col='NO2', n_lags=3):
    for i in range(1, n_lags + 1):
        df[f'{target_col}_lag{i}'] = df[target_col].shift(i)
    df = df.dropna()
    return df

df = create_lag_features(df, 'NO2', n_lags=3)

X = df[['NO2_lag1', 'NO2_lag2', 'NO2_lag3']]
y = df['NO2']

# === 3. Split data ===
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, shuffle=False)

# === 4. Normalisasi ===
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# === 5. Latih model KNN ===
model = KNeighborsRegressor(n_neighbors=5, weights='distance')
model.fit(X_train_scaled, y_train)

# === 6. Evaluasi model ===
y_pred = model.predict(X_test_scaled)
mape = mean_absolute_percentage_error(y_test, y_pred)
print(f"Model berhasil dilatih ✅\nMAPE: {mape:.4f}")

# === 7. Simpan model & scaler ===
joblib.dump(model, "model_no2.pkl")
joblib.dump(scaler, "scaler.pkl")
print("Model dan scaler telah disimpan!")

Kode di bawah ini knn_model.py berfungsi untuk membangun, melatih, dan menyimpan model prediksi menggunakan algoritma K-Nearest Neighbors (KNN) Regressor pada data time series konsentrasi NO2. Proses dimulai dengan membaca dataset dari file CSV yang diberikan, memproses kolom waktu, dan membersihkan data yang kosong pada kolom target (NO2). Selanjutnya, kode ini membuat fitur lag (misalnya NO2_lag1, NO2_lag2, dst.) untuk menangkap autokorelasi dalam data, sehingga nilai NO2 sebelumnya dapat membantu memprediksi nilai saat ini. Setelah itu, data dipisahkan menjadi training set dan test set tanpa diacak (shuffle=False) karena sifat time series, lalu dilakukan normalisasi menggunakan StandardScaler agar semua fitur berada pada skala yang sama. Model KNN kemudian dilatih dengan n_neighbors=5 dan menggunakan bobot jarak (weights='distance'), diikuti dengan prediksi pada test set dan evaluasi performa menggunakan Mean Absolute Percentage Error (MAPE). Terakhir, model yang telah dilatih dan scaler disimpan ke folder model dengan format .pkl, dan fungsi mengembalikan nilai 1 - MAPE sebagai indikator kinerja—semakin tinggi nilai ini, semakin baik model.

import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsRegressor
from sklearn.metrics import mean_absolute_percentage_error
import joblib
import os

def create_lag_features(df, target_col='NO2', n_lags=3):
    for i in range(1, n_lags + 1):
        df[f'{target_col}_lag{i}'] = df[target_col].shift(i)
    df = df.dropna()
    return df

def train_knn_model(data_path, n_lags=3):
    if not os.path.exists(data_path):
        raise FileNotFoundError(f"File data tidak ditemukan: {data_path}")

    df = pd.read_csv(data_path)
    df['time'] = pd.to_datetime(df['time'])
    df = df.dropna(subset=['NO2'])

    # Buat fitur lag untuk memperhitungkan autokorelasi
    df = create_lag_features(df, 'NO2', n_lags)

    # Fitur: NO2_lag1, NO2_lag2, ...
    feature_cols = [col for col in df.columns if 'lag' in col]
    X = df[feature_cols].values
    y = df['NO2'].values

    # Split data
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, shuffle=False)

    # Normalisasi
    scaler = StandardScaler()
    X_train_scaled = scaler.fit_transform(X_train)
    X_test_scaled = scaler.transform(X_test)

    # Model KNN
    knn = KNeighborsRegressor(n_neighbors=5, weights='distance')
    knn.fit(X_train_scaled, y_train)

    # Prediksi dan evaluasi MAPE
    y_pred = knn.predict(X_test_scaled)
    mape = mean_absolute_percentage_error(y_test, y_pred)

    # Simpan model dan scaler
    os.makedirs("model", exist_ok=True)
    joblib.dump(knn, "model/knn_model.pkl")
    joblib.dump(scaler, "model/scaler.pkl")

    return 1 - mape  # semakin tinggi semakin bagus (mirip akurasi)

Evaluasi dan Validasi Model#

Kode Python ini sangat sederhana namun fungsional, dan berperan sebagai fungsi utilitas untuk memuat data dari file CSV. Fungsi load_data(path) menerima argumen path, yaitu lokasi file CSV yang ingin dibaca. Pertama, fungsi memeriksa apakah file tersebut ada di path yang diberikan menggunakan os.path.exists(path). Jika file tidak ditemukan, fungsi langsung melempar FileNotFoundError dengan pesan yang jelas, sehingga pengguna tahu bahwa file yang dimaksud tidak tersedia. Jika file ada, fungsi menggunakan pandas.read_csv(path) untuk membaca file CSV tersebut menjadi DataFrame pandas, yang kemudian dikembalikan oleh fungsi.

Secara ringkas, fungsi ini menjamin keamanan pembacaan file CSV dengan pengecekan keberadaan file sebelum memuatnya ke program, sehingga mencegah error yang tidak diinginkan saat data digunakan dalam analisis atau pelatihan model.

Implementasi Aplikasi Prediksi NO₂ Manyar#

Kode app.py ini merupakan aplikasi web interaktif berbasis Streamlit yang digunakan untuk memprediksi konsentrasi NO₂ harian di Manyar menggunakan model K-Nearest Neighbors (KNN) yang sudah dilatih sebelumnya. Secara keseluruhan, kode ini mengintegrasikan antarmuka pengguna, pemrosesan data, prediksi model, visualisasi, dan unduh hasil menjadi satu aplikasi yang mudah digunakan.

Langkah-langkah dan fungsinya dijelaskan sebagai berikut:

  1. Konfigurasi dan Header: Mengatur tampilan halaman Streamlit (page_title, layout) dan menampilkan judul, caption, serta garis pemisah untuk memperkenalkan aplikasi prediksi NO₂.

  2. Load Data dan Model: Mengecek keberadaan file dataset (NO2_Manyar.csv), model KNN (knn_model.pkl), dan scaler (scaler.pkl). Jika file tidak ada, aplikasi menampilkan pesan error dan berhenti. Jika ada, data CSV dimuat ke DataFrame pandas, kolom waktu diubah menjadi datetime, data kosong pada kolom NO2 dibuang, dan model serta scaler di-load menggunakan joblib.

  3. Input Periode Prediksi: Pengguna memilih tanggal akhir prediksi melalui widget st.date_input. Perhitungan jumlah hari prediksi dilakukan berdasarkan selisih tanggal terakhir di dataset dan tanggal akhir yang dipilih. Validasi memastikan tanggal prediksi selalu setelah data terakhir.

  4. Tombol Prediksi: Saat tombol prediksi ditekan, aplikasi melakukan perhitungan prediksi bertahap untuk setiap hari. Prediksi menggunakan nilai NO₂ terakhir sebagai input, dilakukan normalisasi dengan scaler, kemudian diprediksi dengan model KNN. Hasil prediksi disimpan dalam list dan diubah menjadi DataFrame dengan tanggal sebagai index.

  5. Visualisasi Grafik: Menggunakan matplotlib, aplikasi menampilkan grafik interaktif yang memvisualisasikan data historis (90 hari terakhir) dan hasil prediksi, dengan garis vertikal menandai awal prediksi.

  6. Tabel Hasil Prediksi: Menampilkan DataFrame hasil prediksi dalam bentuk tabel yang bisa digulir di aplikasi.

  7. Evaluasi Kinerja Model: Jika tersedia data aktual untuk periode prediksi, aplikasi menghitung MAPE (Mean Absolute Percentage Error) sebagai metrik evaluasi. Jika tidak cukup data, aplikasi menampilkan informasi bahwa MAPE tidak bisa dihitung.

  8. Unduh Hasil Prediksi: Menyediakan tombol untuk mengunduh hasil prediksi dalam format CSV, sehingga pengguna bisa menyimpan data prediksi untuk analisis lebih lanjut.

Secara keseluruhan, kode ini mengubah model KNN yang sebelumnya hanya berada dalam skrip Python menjadi aplikasi interaktif yang ramah pengguna, memungkinkan prediksi NO₂ harian, visualisasi tren, evaluasi performa model, dan ekspor hasil prediksi tanpa perlu menulis kode tambahan.

# ==========================================================
# app.py (FINAL VERSION - KNN untuk Manyar, versi bersih)
# Sistem Prediksi NO2 berbasis KNN
# ==========================================================
import streamlit as st
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import os
import joblib
from datetime import timedelta
from sklearn.metrics import mean_absolute_percentage_error
from details.utils import load_data

# --- KONFIGURASI STREAMLIT ---
st.set_page_config(
    page_title="Prediksi NO2 Manyar",
    layout="wide"
)

# ==========================================================
# 0. HEADER
# ==========================================================
st.title("🌫️ Sistem Prediksi Konsentrasi NO₂ - Manyar")
st.caption("Menggunakan model KNN untuk memprediksi konsentrasi NO₂ harian berdasarkan data historis.")
st.markdown("---")

# ==========================================================
# 1. LOAD DATA DAN MODEL
# ==========================================================
DATA_FILE = "data/NO2_Manyar.csv"
MODEL_FILE = "model/knn_model.pkl"
SCALER_FILE = "model/scaler.pkl"

# --- Cek dan load file ---
if not os.path.exists(DATA_FILE):
    st.error(f"❌ File data tidak ditemukan: {DATA_FILE}")
    st.stop()

if not os.path.exists(MODEL_FILE) or not os.path.exists(SCALER_FILE):
    st.error("❌ Model atau scaler belum ditemukan di folder 'model/'. Pastikan file .pkl sudah tersedia.")
    st.stop()

# --- Load data dan model ---
df = load_data(DATA_FILE)
df['time'] = pd.to_datetime(df['time'])
df = df.dropna(subset=['NO2'])

knn = joblib.load(MODEL_FILE)
scaler = joblib.load(SCALER_FILE)

# ==========================================================
# 2. INPUT TANGGAL PREDIKSI
# ==========================================================
st.header("🗓️ Pilih Periode Prediksi")

last_date = df['time'].iloc[-1].date()
start_date_forecast = last_date + timedelta(days=1)
st.markdown(f"*Tanggal terakhir dalam data:* `{last_date}`")

target_date = st.date_input(
    "Pilih tanggal akhir prediksi:",
    min_value=start_date_forecast,
    value=start_date_forecast + timedelta(days=7),
    max_value=start_date_forecast + timedelta(days=60)
)

days_to_predict = (target_date - last_date).days

if days_to_predict <= 0:
    st.warning("⚠️ Pilih tanggal setelah tanggal terakhir dalam dataset.")
    st.stop()

# ==========================================================
# 3. TOMBOL PREDIKSI
# ==========================================================
if st.button(f"🔮 Prediksi Selama {days_to_predict} Hari (Hingga {target_date})"):
    with st.spinner("⏳ Model sedang memprediksi..."):
        # Gunakan 4 lag terakhir (karena scaler menggunakan 4 fitur)
        n_features = scaler.n_features_in_
        last_values = df['NO2'].values[-n_features:]
        preds = []

        for _ in range(days_to_predict):
            X_input = np.array(last_values[-n_features:]).reshape(1, -1)
            X_scaled = scaler.transform(X_input)
            pred = knn.predict(X_scaled)[0]
            preds.append(pred)
            last_values = np.append(last_values, pred)

        # Buat dataframe hasil prediksi
        future_dates = pd.date_range(df['time'].iloc[-1] + pd.Timedelta(days=1), periods=days_to_predict)
        result = pd.DataFrame({'Tanggal': future_dates, 'Prediksi_NO2': preds})
        result = result.set_index('Tanggal')

        st.success("✅ Prediksi selesai!")

        # ==========================================================
        # 4. HITUNG MAPE (jika data aktual tersedia)
        # ==========================================================
        if len(df) >= days_to_predict:
            actual_values = df['NO2'].values[-days_to_predict:]
            mape = mean_absolute_percentage_error(actual_values, preds[:len(actual_values)]) * 100
        else:
            mape = None

        # ==========================================================
        # 5. GRAFIK PREDIKSI
        # ==========================================================
        st.header("📈 Hasil Prediksi NO₂")
        fig, ax = plt.subplots(figsize=(12, 5))

        # Data historis (90 hari terakhir)
        ax.plot(df['time'].tail(90), df['NO2'].tail(90),
                label="Data Historis (Aktual)", color='#1f77b4', linewidth=2)

        # Garis batas awal prediksi
        ax.axvline(x=future_dates[0], color='black', linestyle='--', linewidth=1, label='Awal Prediksi')

        # Hasil prediksi
        ax.plot(future_dates, preds, label="Prediksi NO₂", color='red', linewidth=2)

        ax.set_title(f"Prediksi Konsentrasi NO₂ Hingga {target_date}", fontsize=14)
        ax.set_xlabel("Tanggal")
        ax.set_ylabel("Konsentrasi NO₂ (µg/m³)")
        ax.legend()
        ax.grid(alpha=0.3)
        plt.xticks(rotation=45)
        st.pyplot(fig)
        st.markdown("---")

        # ==========================================================
        # 6. TABEL HASIL PREDIKSI
        # ==========================================================
        st.header("📋 Tabel Hasil Prediksi")
        st.dataframe(result, use_container_width=True)

        # ==========================================================
        # 7. METRIK MODEL
# ==========================================================
        st.header("📊 Kinerja Model")
        if mape:
            st.metric(label="MAPE (Mean Absolute Percentage Error)", value=f"{mape:.2f}%")
        else:
            st.info("Tidak cukup data aktual untuk menghitung MAPE.")

        # ==========================================================
        # 8. UNDUH HASIL
        # ==========================================================
        csv = result.to_csv().encode('utf-8')
        st.download_button(
            label="📥 Unduh Hasil Prediksi (.csv)",
            data=csv,
            file_name=f"Prediksi_NO2_Manyar_Hingga_{target_date}.csv",
            mime="text/csv"
